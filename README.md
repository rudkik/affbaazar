# Бот объявлений: канал + сайт + коины

Три части одной системы:

1. **Канал** — витрина объявлений. Писать в него может только бот.
2. **Сайт** — живая лента тех же объявлений с поиском, фильтрами и сортировками; работает на
   собственной независимой базе-дублёре.
3. **Бот** — единственный способ опубликовать объявление: проверяет подписку, берёт коины,
   собирает пост с хэштегами, продаёт платные опции и отдаёт админам кнопки модерации.

## Как это работает

**Подписка (п. 1, 2, 11).** Бот проверяет подписку на канал **при каждой** публикации — отписался,
значит постить не может. Никнейм пишется в базу и обновляется. За подписку начисляется
`signup_bonus` коинов, **один раз за всю жизнь аккаунта** — повторный заход или отписка-подписка
бонус не дают. За приглашённого друга — `referral_bonus`, но только когда друг сам активировался
(подписался и получил свой бонус). Ссылка: «👥 Пригласить друга».

**Публикация объявления (п. 6, 12, 13, 14).** Сценарий в личке бота:

```
📢 Создать объявление
   ├─ правила (если ещё не приняты) → «✅ Принимаю»
   ├─ проверка подписки → кнопки на канал + «✅ Я подписался»
   ├─ рубрика  (16 штук)          → #прямой_рекламодатель
   ├─ вертикаль (20 штук)         → #гемблинг     ← только у рубрик с этим признаком
   ├─ текст объявления
   ├─ картинка?        +price_image коинов
   ├─ закреп?          4 ч → +price_pin_4h, 8 ч → +price_pin_8h
   └─ предпросмотр с ценой → «✅ Опубликовать»
```

Не хватает коинов — бот **сразу** предлагает пакеты для пополнения, без поиска по меню.
Вертикаль спрашивается только у рубрик с флагом «показывать вертикаль» (по умолчанию:
Прямой рекламодатель, CPA сеть, Медиабаинг / Рекламное агентство) — набор настраивается в админке.
У рубрики «Интро/Знакомства» показывается пометка о том, что ссылки на Telegram-каналы
публиковать нельзя.

**Правила (п. 13).** Отдельная кнопка «📜 Правила» и команда `/rules`, плюс обязательный показ
перед первым объявлением. Текст правится в админке; смена `rules_version` заставляет всех
принять правила заново.

**Кнопки под постом (п. 15).** Под каждым объявлением в канале две кнопки:

- **🗑 Удалить** — убирает пост из канала и с сайта, возвращает коины автору.
- **💬 Удалить с комментом** — бот пишет админу в личку «введите комментарий», следующее сообщение
  уходит автору вместе с уведомлением об удалении и возврате коинов.

Telegram показывает кнопки под постом всем подряд, скрыть их нельзя — поэтому нажатие проверяется
по правам: обычный пользователь получит «Доступно только администрации». На сайте управления нет,
как и просили.

**Платные опции (п. 10).** Картинка в посте, закреп на 4 часа, закреп на 8 часов. Цены задаются
в админке. Закреп снимается автоматически: фоновая задача раз в минуту проверяет истёкшие.

**Коины (п. 5, 7, 8).** Покупка прямо в боте через Telegram Stars (ничего подключать не нужно;
для классического биллинга — `PAYMENT_PROVIDER_TOKEN`). Админ начисляет вручную:
`/give @username 100` или из веб-админки. При удалении объявления администрацией коины
возвращаются — ровно один раз. Каждое движение пишется в реестр `token_tx`.

**Сайт (п. 4).** Живая лента: поиск по тексту, автору и хэштегу, фильтры по рубрике, вертикали,
типу вложения и закреплённым, сортировки, обновление без перезагрузки. Данные берутся из
**отдельной базы `site.db`**, не из рабочей базы бота.

**Админка (п. 3).** Статистика (пользователи, объявления, коины, платные опции, топ рубрик),
объявления с удалением и комментарием, пользователи с начислением коинов, рубрики и вертикали
(правка названий, тегов, порядка, признака вертикали), все настройки и цены, платежи.

Премодерации нет (п. 9) — объявление уходит в канал сразу.

## Рубрики

16 типов объявлений и 20 вертикалей засеваются при первом запуске, хэштег генерируется из
названия: «Медиабаинг / Рекламное агентство» → `#медиабаинг_рекламное_агентство`. Названия, теги,
порядок, признак «показывать вертикаль» и активность правятся в админке, вкладка «Рубрики».

## Быстрый старт

```bash
cp .env.example .env && nano .env      # BOT_TOKEN, ADMINS, ADMIN_PASSWORD, SECRET_KEY
make env && make deploy                # боевой сервер: Docker + nginx + HTTPS (см. DEPLOY.md)
docker compose up -d --build           # или ./start.sh для systemd
```

Затем в личке бота (вы должны быть в `ADMINS`):

1. `/set_channel @ваш_канал` — бот обязан быть в канале **администратором** (постить, закреплять,
   удалять).
2. «📢 Канал и цены» — задать цены объявления, картинки и закрепов.
3. «⚙️ Глобальные настройки» → «📜 Текст правил» — свои правила.
4. Проверить: `/post` с другого аккаунта.

Деплой, nginx, HTTPS, бэкапы — в [DEPLOY.md](DEPLOY.md).

## Команды

Пользователь: `/start`, `/post` (создать объявление), `/rules`, `/balance`, `/buy`, `/ref`, `/site`.

Админ бота (то же доступно кнопками меню):

| Команда | Что делает |
|---|---|
| `/admin` | Панель администратора |
| `/set_channel <@канал>` | Канал для объявлений (с проверкой прав бота) |
| «📢 Канал и цены» | Канал, все цены, статистика по объявлениям |
| `/settings` | Глобальные настройки |
| `/price_post`, `/price_image`, `/price_pin_4h`, `/price_pin_8h` | Цены (через меню настроек) |
| `/give @user 100` | Начислить или списать коины |
| `/stats` | Сводка |
| `/refund <charge_id>` | Возврат оплаты Stars |
| `/connect_chat`, `/chats` | Подключить чат и его настройки (гейт по подписке в чате) |
| `/msg_ttl`, `/check_limit`, `/restrict_hours`, `/restricted_text` | Настройки чата |

Русские алиасы: `/подключить`, `/чаты`, `/каналы`, `/канал`, `/цены`, `/правила`, `/настройки`,
`/время`, `/лимит`, `/блокировка`, `/текст`, `/выдать`, `/статистика`, `/помощь`.

В подключённом чате (ответом на сообщение): `/del` — удалить и вернуть коины, `/repost` — в канал,
`/unrestrict` — снять ограничение.

## Настройки

| Ключ | По умолчанию | Значение |
|---|---|---|
| `ad_channel_id` | — | канал для объявлений |
| `price_post` | 10 | цена объявления |
| `price_image` | 5 | доплата за картинку |
| `price_pin_4h` | 15 | закреп на 4 часа |
| `price_pin_8h` | 25 | закреп на 8 часов |
| `signup_bonus` | 30 | коинов за подписку (единоразово) |
| `referral_bonus` | 10 | коинов за активировавшегося друга |
| `rules_text` / `rules_version` | см. код | правила и их версия |
| `intro_note` | см. код | пометка для «Интро/Знакомства» |
| `token_packages` | 50/100/250 ⭐ | пакеты покупки, JSON |

| `check_limit` | 10 | подряд неудачных проверок подписки в чате |

## Логи

```
logs/<chat_id или channel_id>/01_09_2026.log      время | user_id | @ник | текст в одну строку
logs-restricted/<chat_id>/restricted_<дата>.log   превысившие лимит проверок
logs/bot.log                                      технический лог (ротация 5×5 МБ)
```

## Структура

```
bot.py                  polling + веб-сервер + фоновое снятие закрепов
app/ads.py              ядро объявлений: цена, публикация, закреп, удаление с возвратом
app/db.py               основная база, настройки, рубрики, правила
app/site_db.py          независимая база-дублёр для сайта
app/tokens.py           реестр коинов
app/subscription.py     проверка подписки
app/services.py         временные сообщения, шаблоны, репосты, возвраты
app/action_log.py       файловые логи
app/handlers/           post (создание объявления) | moderation (кнопки под постом) |
                        admin | user | chat_guard | payments
app/web/                FastAPI: лента, API, админка
```

## Проверки

```bash
pip install -r requirements-dev.txt
./tests/run.sh
```

Девять наборов на временных базах с подменённым Telegram-ботом, токен не нужен:

- `smoke.py` — базы, реестр коинов, формат файловых логов, веб-API и авторизация админки;
- `test_gate.py` — гейт в чате: удаление, лимит проверок, блокировка, списание, возврат;
- `test_publish.py` — публикация через бота, рефералы, защита от повторного бонуса, репост;
- `test_flows.py` — реф-ссылки, меню, админ-команды, права, счёт и оплата Stars, автоудаление;
- `test_ads.py` — цены, публикация в канал с хэштегами, закреп и автоснятие, удаление
  с комментом и возвратом, права на кнопки, поведение при сбоях Telegram;
- `test_ad_flow.py` — весь сценарий объявления: правила, подписка, рубрика, вертикаль, текст,
  картинка, закреп, публикация, удаление с комментом;
- `test_edge.py` — краевые случаи: двойные нажатия, античит бонусов, постинг после отписки,
  подмена id рубрики, нулевые и отрицательные цены, HTML-инъекции, битые настройки;
- `test_web_admin.py` — админ-API: объявления, удаление с возвратом, CRUD рубрик, цены,
  статистика, закрытость без авторизации;
- `test_races.py` — параллельные нажатия: двойной тап «Опубликовать» и «Удалить»,
  одновременная активация. Деньги и посты не дублируются.
